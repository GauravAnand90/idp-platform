# Internal Developer Platform (IDP)

## Overview

This project demonstrates an Internal Developer Platform (IDP) using Backstage.

## Features

- Self-service developer portal
- Software catalog
- Service templates
- Golden paths
- Kubernetes integration
- CI/CD integration

## Architecture

Developer → Backstage → GitHub → CI/CD → Kubernetes

## Technology Stack

- Backstage
- Kubernetes
- GitHub Actions
- YAML
- Terraform

```text
├── backstage

└── docs
```

## Benefits

- Improved developer productivity
- Standardized deployments
- Self-service onboarding
- Reduced operational overhead
